LSJI

Language Service JavaScript Interface

Antigravity-level agentic autonomy meets the ultimate simplicity of self-hosting.

Apache 2.0 Node.js 22+ @game_ryo/lsji

Overview

LSJI (Language Service JavaScript Interface) is a production-grade framework for hosting AI agents with zero infrastructure complexity. Simply provide a Gemini, OpenAI, or Anthropic API key (or run locally with Ollama) and deploy autonomous agents with built-in safety, durability, and observability.

Core Capabilities

  • LLM Agent Runtime — ReAct pattern with tools, memory, and streaming
  • HITL (Human-in-the-Loop) — Approval gates for sends, charges, code execution
  • Durability — Checkpointing & recovery from any failure
  • Idempotency — Duplicate prevention on retries
  • Budget Controls — Token/cost limits with circuit breaker
  • Web Control Panel — Real-time thought logs, approval queue, budget monitoring
  • Plugin System — Drop-in custom tools via lsji-plugins/
  • Pluggable Storage — node:sqlite (built-in), better-sqlite3, or in-memory

Quick Start

# Install
npm install @game_ryo/lsji

# Set your API key (Gemini, OpenAI, or Anthropic)
export GEMINI_API_KEY="your-gemini-key"

# Start the runtime server with web UI
npx lsji serve

# Open http://localhost:3456

Architecture

🤖 LLM Agent Framework

ReAct pattern with multi-provider support, tool registry, and three-tier memory system.

🛡️ Production Systems

HITL approvals, budget tracking, circuit breaker, idempotency, durable execution.

🌐 Runtime Server

Express + Socket.io with React control panel for real-time agent management.

🔌 Plugin System

Dynamic tool loading from lsji-plugins/ directory.

CLI Commands

# Runtime server with web UI
lsji serve [--port 3456] [--no-ui]

# LLM Agent operations
lsji agent run --task "Your task" --provider gemini --model gemini-1.5-flash
lsji agent run-durable --task "Analyze codebase" --workflow-id my-analysis

# Budget & approvals
lsji budget status --budgetId my-project
lsji hitl list
lsji hitl approve --id  --reason "Approved"

# Plugins
lsji plugin list
lsji plugin create --name my-tools

# RL (legacy)
lsji train --episodes 500
lsji play --hand 0

Programmatic Usage

import { createLLMAgent, startServer } from '@game_ryo/lsji';

// Create agent with full production features
const agent = await createLLMAgent({
  llm: { 
    provider: 'gemini', 
    model: 'gemini-1.5-flash', 
    apiKey: process.env.GEMINI_API_KEY 
  },
  budget: { maxCostPerRun: 5, maxCostPerDay: 50 },
  hitl: { enabled: true, defaultTimeout: 300000 },
  memory: { conversation: true, episodic: true, semantic: true },
});

const result = await agent.run("Research TypeScript best practices and create a summary");
console.log(result.answer);

// Or start the full runtime server
const server = await startServer({ port: 3456 });
